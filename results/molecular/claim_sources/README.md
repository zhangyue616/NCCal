# Molecular claim sources

These small inputs support the explicit scientific selectors in `verify/molecular_claim_bindings.py`. They contain derived activation values, positional-audit categories, grouped score/label counts, chemical-definition partitions, frozen configurations and archived sensitivity rows. They contain no bulk structure strings, model checkpoints or per-input experimental benchmark targets. `SOURCE_IDENTITIES.json` identifies the original files and SHA-256 values and describes each extraction.

The binding module returns `{article_position: {value, source, operation}}`. Values use the units displayed at that article position. Percentages are already multiplied by 100, and the terminal-block response coefficient is expressed relative to `10^-5`. Operations beginning `Design` are frozen protocol or plotting parameters; they are not effect estimates.

Several calculations use lower-level evidence: hydroxyl means deduplicate physical atom identities; positional verification counts original per-molecule categories; notation support keeps all three strings of each parent; average precision preserves exact float32 score ties; the census diagnostic AUROCs use only originally usable determinate neurons; unchanged-environment edit changes weight molecules equally and retain the development SD scale.

The fragment exploration preserves every original concept/layer/scope row. Its pyridine target-output rank is an archived scientific field for the specific block-two atom-only intervention. The small fragment does not contain the complete 199-output perturbation vectors needed to independently re-rank that case. The maximum terminal-block atom-only response is recalculated across the saved row-level maxima. Neither source binding is a claim that the original exploratory model queue was rerun.

Historical original-file hashes describe the source files, not these extracted distribution files. No source hash is rewritten to make a new extraction appear to be an original frozen artifact.
