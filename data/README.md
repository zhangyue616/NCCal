# Included analysis inputs

This folder contains selected molecular records, atom-level concepts, mapping anchors and ordered development and confirmation inputs.

| Folder or file group | Contents | Manuscript or SI section |
| --- | --- | --- |
| `derived/cross_model_comparison/corpus/` | Molecular source pool, exploratory subset and primary cohort | SI S-A–S-C |
| `derived/cross_model_comparison/concepts/` | Atom-level concept dictionary, labels and atom indexes | SI S-A–S-C |
| `fixed_coordinate_analyses/chemistry/` | Molecular corpus, concepts, mapping anchors and ordered development/confirmation records | SI S-D–S-E, S-H, S-J |

## Names used here

| Name in files | Meaning |
| --- | --- |
| D / T | Development set / confirmation set. |
| H4 | Primary cohort (10,000 molecules), drawn after excluding the original pool. |

Large molecular activation caches and other omitted inputs are listed in `../reproduction/OMITTED_INPUTS.json`.
