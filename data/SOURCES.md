# Source identity and reuse

The tables below identify the source material used in this study. The asset index gives byte sizes, SHA-256 digests and revision identifiers where the original provider supplied them. A rolling URL must yield the recorded digest to reproduce that snapshot.

| Source | Source and rights evidence | Distributed here |
|---|---|---|
| PubChem | [NCBI data policy](https://www.ncbi.nlm.nih.gov/home/about/policies/) distinguishes government and contributed records. The frozen CID–SMILES file is content-pinned in `asset_index.json`. | Identifiers and first-party measurements. |
| PDB | [wwPDB usage policies](https://www.wwpdb.org/about/usage-policies). The licence page was unavailable for offline verification here. The structure manifest identifies the cached releases by bytes and digest. | PDB IDs and study-derived coordinates, features and measurements. |
| SIFTS | [SIFTS at EMBL-EBI](https://www.ebi.ac.uk/pdbe/docs/sifts/). A separate redistribution grant for the retrieved XML files was not established in the stored records. | PDB/UniProt identifiers and derived mappings. |
| UniProt | The archived [UniProt licence](https://rest.uniprot.org/help/license) specifies CC BY 4.0, subject to third-party rights. | Identifiers, derived selections and study results. |
| BACE and ESOL | [BACE loader](https://github.com/deepchem/deepchem/blob/455d07f3e17e880a4d980b5b0365e4a02b417e14/deepchem/molnet/load_function/bace_datasets.py) and [ESOL loader](https://github.com/deepchem/deepchem/blob/455d07f3e17e880a4d980b5b0365e4a02b417e14/deepchem/molnet/load_function/delaney_datasets.py). First-party code uses the MIT licence. First-party derived data, figures and documentation use [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Upstream providers retain their respective rights. Database snapshots, experimental benchmark CSVs, author label tables and pretrained weights are obtained separately. Use `python data/fetch.py` to list the acquisition keys. A locally obtained file can be checked offline with `python data/fetch.py KEY --check FILE`. To retrieve one permitted asset, use `python data/fetch.py KEY --dest DIRECTORY`. Upstream access restrictions and terms apply.
