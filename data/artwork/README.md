# Artwork input provenance

The result tables and arrays in `results/artwork/` are author-owned frozen analysis outputs. Molecular depictions are generated with RDKit and small derived geometries. No third-party illustration, manuscript page, paper PDF or external icon library is required. Schematic arrows, locks, grids and other icons are drawn by the included Python code. System fonts are not redistributed.

`molecular_example_depictions.json` contains eighteen fixed model/unit/concept records and six molecules per record. Each cell retains its PubChem CID, derived 2D MolBlock, atom indices, saved response vector and target-atom indices. These plotting intermediates were recovered from already cached activations and the original fixed selection records, without model inference, fitting or a new selection study. Positive-atom counts and precision@100 were checked for all eighteen units. The old raster example tiles are not included.

`protein_masked_geometry.json` and `protein_exposure_geometry.json` contain derived N/CA/C/O backbone geometries and secondary-structure annotations for PDB IDs 2CZL and 2XMX, respectively. Both use chain A and contain 270 residues for drawing. The renderers derive views, ribbons and highlights from these coordinates. Raw deposited coordinate files and SIFTS snapshots are not distributed. The optional download helper records public IDs and URLs; it performs no request unless explicitly requested.

`molecules/` retains selected author-generated 2D layouts, atom alignment and scalar responses. `generated/` contains reproducible local protein components and manifests; missing components are generated by `figures/render.py` from the derived backbone files.

Preparation was offline. Public licensing pages were not rechecked during this stage; local provenance and review records are retained outside the distribution for the repository release review.
