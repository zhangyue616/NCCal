# Analysis protocols and deviations

This folder contains English translations of the study's analysis protocols and a summary of the recorded execution deviations.

| Folder or file group | Contents | Manuscript or SI section |
| --- | --- | --- |
| `fixed_coordinate_analyses/CHEMISTRY_*.en.md` | Molecular sources, development/confirmation rules and intervention specifications | SI S-D–S-E, S-H |
| `fixed_coordinate_analyses/PROTEIN_*.en.md` | Protein metadata, fitted-reference and fresh-confirmation protocols | SI S-G–S-H |
| `sensitivity_analyses/*.en.md` | Lineage, atom-anchor, scaffold-unseen, standardized-rotation and paired-dose protocols | SI S-I; population eligibility in S-L |
| `reconstruction_and_replacement/PROTOCOL.en.md` | Two-coordinate continuous activation reconstruction and replacement | SI S-J |
| `DEVIATIONS.md` | Memory interruptions, numerical-threshold exceedance and dose-verification recovery | SI S-G, S-I.4 |

## Names used here

| Name in files | Meaning |
| --- | --- |
| T | Confirmation set, in protocol file names. |
| root / supervisor / research operator | Supervising AI sessions described in the manuscript's Acknowledgements and the Supplementary Information's “Use of AI in executing the study”. |

The Chinese protocol originals are not part of this release and govern if the translations differ. Lock and receipt files mentioned within the protocols are internal process records and are not part of this release.
