# Molecular readability and coordinate calibration

The pilot screens concept matches in trained, initialized and rotated axes. The confirmatory audit fixes 173 readable atom concepts and uses 199 independently initialized networks and nine rotations. Readability uses concept-level best-lift profiles. Axis preference subtracts median log rotated lift. Normalized within-concept midranks are averaged across concepts; the trained network is included in the rank denominator. Both directional criteria must pass 0.05/8 for the eight-checkpoint family. MoLFormer has a separate twelve-layer selection rule, including an unconstrained axis-preference maximum test. These design histories remain distinct.

The stored profile arrays, rather than the published folds, are the inputs to CPU verification. Protocol identities preserve the original source hashes; retrospective replay does not renew result blindness. Untrained and rotated axes with readable labels are retained as adverse evidence. Graph checkpoints failing the joint criterion remain in the profile archive.

Full activation extraction requires the public checkpoint versions in the model-source manifest, the concept definitions and the archived CID exclusions. The standalone smoke exercises the ChemBERTa native measurement site on a derived public-input fixture. It is not a full nine-model extraction or a new calibration.
