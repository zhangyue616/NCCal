# Deviations and scope

An initial optimizer-pilot path error occurred before opening an activation array or taking an optimizer step; only the input path was corrected. Four reconstruction-only pilot fits selected learning rate 0.001 by the prewritten mean-log-FVU rule. No concept labels entered that choice. Synthetic engineering timings are not scientific fits. Later budget/dispatch recovery records retain the identities and all 504 completed fits; this package recalculates their scored profile comparisons and does not claim to have retrained them in a clean environment.
