# Deviations and scope

The local candidate cache already supplied all 3,000 molecules, so no source download was needed. MoLFormer retained all 768 channels and its five frozen heads were averaged within each task. A final normalization layer missing from an early wrapper was restored and checked before new scoring. Identity and full-layer replay differed only by bounded batch arithmetic in outputs. A variable-shadowing defect in the first following calculation was corrected by an independent weighted covariance calculation; final Pearson strata use the corrected table. Some array headers were normalized without changing data bytes. New software could not regenerate old random states from the seed; archived initialization states were exported from the original library and replayed before new extraction.
